# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Free web-icon libraries for the ph-oton web stack (`groupId com.helger.photon.icon`). One Maven artifact per icon set so an app pulls only what it uses. Extracted from the former `ph-oton-icon` module of ph-oton.

Four modules, each self-contained: `ph-oton-icon-fontawesome4`, `-fontawesome5`, `-materialdesign`, `-bootstrap`.

## Build & test

- Requires Java 17+ (CI builds 17, 21, 25).
- Build/test everything from the repo root: `mvn clean install`. The root is a POM aggregator with no code of its own — build from root to cover all modules.
- CI runs `mvn --batch-mode --update-snapshots install`.

## Per-module structure

Each module has package `com.helger.photon.icon.<library>` with the same three main classes:
- `E<Library>Icon` — enum of all icons, implements `IIcon`, each constant tied to a CSS class.
- `C<Library>CSS` — `ICSSClassProvider` constants for every CSS class.
- `EIconCSSPathProvider` — `ICSSPathProvider` enum for the library's stylesheets.

Bundled fonts/CSS live on the classpath under `external/<library>/<version>/...`; supplementary CSS under `ph-oton/...`. The `EIconCSSPathProvider` paths must match this physical resource layout (`minifiedPathFromPath()` auto-derives the `.min.css` sibling).

## Generated code — do not hand-edit

`E<Library>Icon` and `C<Library>CSS` are generated by the `Main*` tools under each module's `src/test/java/.../tools/supplementary/`, from upstream icon metadata (`icons.json` / CSS). To change icon constants, re-run the generator — do not edit the enums by hand. See the `/regen-icons` skill.

## Code style (differs from Java defaults)

- Hungarian notation: `m_` instance fields with a type letter (`m_aPP`), typed params (`sPath`, `bRegular`, `a…` for objects). See `~/.claude/rules/naming.md`.
- Nullability: **jspecify** `org.jspecify.annotations.NonNull` / `Nullable` — NOT `javax`/`jakarta`. Plus helger `com.helger.annotation.Nonempty`, `...style.ReturnsMutableCopy`.
- Formatting (enforced by the Eclipse formatter inherited from `com.helger:parent-pom`): space before `(` in calls/decls (`getCSSItemPath ()`), Allman braces.
- Apache-2.0 license header on every `.java`/`.xml`/`.yml`; template at `src/etc/license-template.txt`, enforced by the parent-pom license plugin.
- Enum constants for numeric icon names are underscore-prefixed (`_0_CIRCLE`).

## Versions

Module POMs specify no dependency versions — they come from BOM imports in the root POM. Move the whole stack by bumping `ph-commons.version` and `ph-oton.version` properties there.

## Git

Changes are committed directly to `main` (no PR required). Do not commit or push unless asked.
